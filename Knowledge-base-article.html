How to Reinstall Microsoft Office When It Is Missing or Removed on Windows

Written by: Kavyashree T  |  Last updated: 12 November 2026  |  Category: Software Installation

Overview

If Microsoft Word, Excel, or PowerPoint suddenly disappears from your Windows computer, you may need to repair or reinstall Microsoft Office.

This issue can occur after an accidental uninstallation, a system update, or a software cleanup. In some cases, Office may still be installed, but its applications are not working correctly.

This guide explains how to check whether Office is installed, repair an existing installation, and reinstall it using your Microsoft account.

Applies to

  • Windows 10 and Windows 11
  • Microsoft 365
  • Licensed versions of Microsoft Office, including Office 2019, 2021, and 2024
  • Word, Excel, PowerPoint, and Outlook

Common symptoms

You may experience one or more of the following issues:

  • Microsoft Word, Excel, or PowerPoint icons are missing from the Start menu.
  • Office applications do not open when selected.
  • Windows asks you to choose an application when opening an Office document.
  • Microsoft Office no longer appears in the list of installed applications.
  • You receive an error message when trying to open an Office application.

Possible causes

Microsoft Office may become unavailable for several reasons:

  • Office was accidentally uninstalled.
  • A system cleanup or third-party application removed Office files.
  • A Windows update interrupted or damaged the installation.
  • Office installation files became corrupted.
  • The Office installation is incomplete.

Before you begin

Before reinstalling Microsoft Office, make sure you have the following ready:

  • A stable internet connection.
  • Access to your Windows computer with administrator permissions.
  • The Microsoft account associated with your Office purchase or subscription.
  • Your work or school account, if Office was provided by your organisation.

Save any open work and close other applications before starting the installation.

Step-by-step instructions

Step 1: Check whether Microsoft Office is still installed

First, check whether Office is already installed on your computer.

  1. Press Windows + I to open Settings.
  2. Select Apps, then open Installed apps.
  3. Search for Microsoft 365 or Microsoft Office in the application list.

    On Windows 10, open Settings > Apps > Apps & features.

  4. Check whether Microsoft Office or Microsoft 365 appears in the list.

If Office is listed: It may only need a repair. Continue to Step 2.

If Office is not listed: The application may have been removed. Skip to Step 3 and reinstall it.

Step 2: Repair the existing Office installation

If Office appears in the installed applications list but does not work correctly, try repairing it before reinstalling.

  1. Open Settings > Apps > Installed apps.
  2. Find Microsoft 365 or Microsoft Office.
  3. Select the three-dot menu next to the application.
  4. Choose Modify.
  5. Select Quick Repair, then click Repair.
  6. Wait for the repair process to finish.

If the problem continues, repeat the process and select Online Repair instead.

Quick Repair checks and replaces damaged installation files without requiring a full internet-based repair. Online Repair performs a more thorough repair and may require an internet connection.

Note: The available repair options may vary depending on your Office installation type.

If Office is still not working after the repair, proceed to the next step.

Step 3: Sign in to your Microsoft account

If Office is missing from your computer, download it again from Microsoft's official website.

  1. Open your web browser.
  2. Visit https://m365.cloud.microsoft/apps.
  3. Select Sign in.
  4. Enter the Microsoft account associated with your Office licence.

    If your organisation provided Office, sign in using your work or school account instead.

  5. After signing in, look for the Install apps option.

If you cannot see the installation option, your account may not have an eligible Office licence or your organisation's administrator may not have assigned one.

Step 4: Download and install Microsoft Office

Once you have signed in successfully:

  1. Select Install apps.
  2. Choose the available Microsoft 365 or Office installation option.
  3. Wait for the setup file to download.
  4. Open the downloaded setup file.
  5. If Windows displays a User Account Control message asking whether you want to allow the application to make changes to your device, select Yes.
  6. Allow the installation to complete. This may take several minutes, depending on your internet connection and computer performance.

When the installation finishes, you should see a confirmation message indicating that Office is installed.

Step 5: Open Office and activate it

After installation, check whether the applications are working correctly.

  1. Open the Windows Start menu.
  2. Search for Microsoft Word or Excel.
  3. Select the application to launch it.
  4. Sign in using the Microsoft account associated with your Office licence, if prompted.
  5. Accept the licence agreement or follow any activation instructions displayed on the screen.

If an Activation Wizard appears, follow the instructions to complete activation.

Step 6: Verify the installation

Finally, confirm that Office is installed and working as expected.

  1. Open Microsoft Excel.
  2. Create a blank workbook.
  3. Enter a few words or numbers into a cell.
  4. Save the workbook.
  5. Close Excel and open the saved file again.
  6. Check File > Account to review the product and activation information.

If the file opens successfully and Office shows that the product is activated, the installation is complete.

Additional troubleshooting

If Microsoft Office still does not install or open correctly, try the following:

1. Restart your computer

A restart can resolve temporary system issues and complete pending installation changes.

2. Check your internet connection

Make sure your connection is stable. A slow or interrupted connection can prevent Office from downloading or installing properly.

3. Install pending Windows updates

Open Settings > Windows Update and check whether any updates are available. Install relevant updates and restart your computer if required.

4. Use Microsoft's installation troubleshooter

If the installation continues to fail, visit Microsoft's official support website and use the Microsoft 365 installation troubleshooter or the available Get Help troubleshooting options.

5. Check your Office licence

Make sure the Microsoft account you are using has an active Microsoft 365 subscription or an eligible Office licence. If Office was provided by your organisation, contact the IT administrator to verify your licence.

When to escalate the issue to the IT support team

If none of the above steps resolves the problem, escalate the issue to the IT support team for further investigation.

When creating a support ticket, include the following information:

  • A brief description of the issue.
  • The exact error message or error code, if available.
  • Your Windows version (Windows 10 or Windows 11).
  • The Microsoft Office version, if known.
  • The account type used for installation (personal, work, or school).
  • Troubleshooting steps already performed.
  • A screenshot of the error message, if available.

Providing these details will help the support team identify the cause and resolve the issue more efficiently.

Conclusion

Missing Microsoft Office applications do not always mean that you need to reinstall the entire Office suite. Start by checking whether Office is installed and try repairing it if necessary. If the applications have been removed, download and reinstall Office using the Microsoft account associated with your licence.

Following these steps should help restore access to Word, Excel, PowerPoint, and other licensed Office applications.
