NexusSearch: Unified Digital Intelligence Hub

Capstone project · Python, Flask, SQLite

Problem

Finding a course, a job, a product or a scholarship means opening many websites and repeating the same search on each one.

Solution

NexusSearch takes one query, searches every platform in the chosen category, and shows the results together as cards, with charts to compare them.

What it searches

Courses
Udemy, Coursera, edX, YouTube, Khan Academy, Skillshare
Jobs
LinkedIn, Indeed, Naukri, Glassdoor, Internshala, Wellfound
Shopping
Amazon, Flipkart, Myntra, Meesho, Snapdeal, Croma
Scholarships
NSP India, Buddy4Study, AICTE, Vidyasaarathi, PFMS
Coding
LeetCode, HackerRank, CodeChef, Codeforces, GeeksforGeeks
Entertainment
Netflix, Disney+ Hotstar, Amazon Prime, YouTube, SonyLIV, ZEE5

How a search runs

  1. The user logs in or registers.
  2. The dashboard shows six category cards with an animated slider.
  3. The user picks a category, for example Courses.
  4. The user types a query, such as "Python programming under budget".
  5. The app searches DuckDuckGo with a site-specific query for each platform.
  6. Results appear as cards with platform, price, salary or rating.
  7. Charts are generated: a pie chart of platform distribution and a bar chart of ratings.

Features

  • Login and registration with duplicate email detection
  • Real web scraping with DuckDuckGo search and BeautifulSoup
  • Results cards with platform, price, rating and details
  • Visual charts built with Chart.js
  • AI assistant module for handling search queries
